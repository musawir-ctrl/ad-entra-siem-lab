# Active Directory + Entra ID Lab with SIEM Monitoring

A small enterprise identity lab: Windows Active Directory synced to Microsoft Entra ID, monitored by a Wazuh SIEM, and tested with simulated attacks.

## Status
Work in progress. Started September 2026.

## Goals
- Build and administer a Windows domain (AD DS, DNS, Group Policy)
- Automate user onboarding/offboarding with PowerShell
- Integrate with Microsoft Entra ID (MFA, sync)
- Detect suspicious activity with Wazuh and document incident responses
